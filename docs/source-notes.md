## 프로젝트 근거와 표현 범위

### 01. 실적 정산과 자료 검증

- 기간·소속·상담 실적 정산·정산 오류 0건은 사용자가 제공한 작업 지시의 사실 서술을 반영했습니다.
- 업무 단계는 그 경험에 기반한 재구성 도식입니다. 회사 내부 정산표, 고객정보, 임의로 만든 업무 산출물은 게시하지 않았습니다.
- 채권 결제나 KYC 업무 경험을 주장하지 않습니다.

### 02. Multi-Asset Morning Briefing

- 공개 저장소: https://github.com/bucheoncityboy/multi-asset-morning-briefing
- 실제 코드, README, 테스트 fixture를 검토했습니다.
- 구현 근거: 미국 Cboe와 한국 ECOS 관측일의 독립 판별, Treasury·Cboe·ECB·ECOS 데이터 조회, 관측일·단위·가격 기준 보존, stale 값 배제, 원천별 실패 격리, 7개 섹션 출력.
- 작성시간 약 40분에서 10분 이내로 줄었다는 값은 저장소 README의 학회원 피드백 서술 및 사용자 제공 지시를 기준으로 했습니다. 실험 통제 성과로 표현하지 않았습니다.
- 실행 샘플은 기존 포트폴리오의 `samples/2026-10-07.html`을 재사용했고 학회 직접 작성 브리핑과 구분했습니다.
- K-Skill 기여: https://github.com/NomaDamas/k-skill/pull/675

### 03. 해외 IB Credit 리서치 분석

- 시장 범위와 결론은 사용자가 제공한 작업 지시를 반영했습니다: USD IG 및 EUR HY의 1–3년 구간, 캐리·듀레이션·신용스프레드 관계.
- 공개 저장소 인덱스에서 이 분석의 공개 보고서나 데이터 파일을 확인하지 못했습니다.
- 따라서 자체 작성한 질적 비교만 표시하고, 수익률·스프레드 수치, 유료 IB 원문·표·차트, 존재하지 않는 자료 링크는 게시하지 않았습니다.

### 04. 국고채 3s10s 이벤트 연구

- 저장소: https://github.com/bucheoncityboy/krw-rates-integrated-research
- README와 공개 PPTX의 15개 슬라이드 텍스트를 대조했습니다.
- 분석 범위: 공통 관측일 1,084개, 2022.01–2026.05 정책결정 36회, D−1 대비 D+1·D+5. 발표자료의 시장 관측은 2026.06.05까지입니다.
- D+1 3s10s 평균 +0.6bp, 중앙값 +0.4bp, 확대 19회, 축소 17회, `|Δ3Y| > |Δ10Y|` 21회는 전체 이벤트 연구의 결과입니다.
- 사례별 DV01 수익·손실은 양쪽 DV01을 각각 280만원/bp로 둔 가상 민감도 계산입니다. 전체 표본 백테스트, 실거래, 특정 국채 선물의 실측 DV01이나 인과 추정이 아닙니다.
- 발표자료: https://github.com/bucheoncityboy/krw-rates-integrated-research/blob/main/KRW_Rates_Integrated_Research_Portfolio.pptx
- 팀 내부학술제 1위와 팀장 역할은 사용자 제공 지시 및 사이트에 재사용한 활동 이력에 근거합니다.
